This is my collective with interchangeable heads. When I'm flying helicopters it's a collective; when I fly warbirds I'll be able to swap heads and lock the arm in place.

## The heads

Currently I only have the Huey head. The warbird head is a work in progress. It'll be WWII inspired, likely based on the Spitfire. I guess I'll build a few...

The Huey head is based on the one from [hc265ma.org](https://hc265ma.org), modified to make it easier to print and to fit my requirements. It needs to be redesigned slightly because it sits too high, which makes it a little tricky to operate.

![The Huey head](/assets/images/force-feedback-collective/huey-head.jpg){: .center-image .small-image }

## Quick release

The quick release uses a camera QR plate with a pogo connector for USB. The plate locks the head to the arm, and the pogo connector carries the signal across the joint without any exposed cable.

![The head's camera plate](/assets/images/force-feedback-collective/quick-release.jpg){: .center-image .small-image }

![The pogo connector on the head](/assets/images/force-feedback-collective/pogo.jpg){: .center-image .small-image }

## Throttle twist

The throttle twist is an AS5600 magnetic encoder, completely concealed inside the grip assembly.

## Grip

The grip is Siraya Tech TPU Air. It's magical stuff.

![The grip with the quick release plate](/assets/images/force-feedback-collective/grip.jpg){: .center-image .small-image }

## Force feedback

I used a centering spring effect with aggressive gradients to actively reduce the range of the collective and also to make it stay fixed in place. Plus some static damping.

![The collective installed in the sim](/assets/images/force-feedback-collective/in-sim.jpg){: .center-image .small-image }

![The collective standing on the sim base](/assets/images/force-feedback-collective/standing.jpg){: .center-image .small-image }

Now I'm truly hooked on helicopters. A proper collective really makes all the difference, and along with FFB on all the flight controls it makes flying much more intuitive.
